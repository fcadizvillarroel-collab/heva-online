GUÍA RÁPIDA
HEVA genera.
HEVA Review perfecciona.
Una herramienta complementaria, diseñada para no intervenir el sistema original.
01
Genera en HEVA
Crea el material habitual en HEVA y descárgalo en Word o PowerPoint.
02
Importa aquí
Arrastra el archivo o pégalo. El texto se extrae en el navegador sin subirlo a internet.
03
Diagnostica
Revisa densidad, repeticiones, actividades, estructura y aspectos de accesibilidad.
04
Mejora conmigo
Descarga el expediente, adjúntalo a ChatGPT y pide una revisión pedagógica profunda.
05
Recupera tu revisión
Importa el archivo corregido o pega el resultado. Compáralo con el original.
06
Exporta
Guarda Word, PowerPoint o Markdown. Mantén un historial de versiones en tu navegador.
¿ChatGPT revisa automáticamente desde esta web?
No. El modo manual funciona gratis y sin API de OpenAI. El modo automático utiliza las API de HEVA y su cuota de proveedores. Para la revisión profunda debes enviar el expediente a este chat. La conexión directa entre aplicaciones requeriría una API y permisos específicos.
