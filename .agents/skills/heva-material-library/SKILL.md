# HEVA Library

1. Lee AGENTS.md y el registro de Fase 3 antes de editar.
2. Usa el historial y su identidad de material para mostrar versiones, clasificar y encontrar candidatos. Revisa la visibilidad de las pautas antes de sugerir un intercambio.
3. Reutiliza estos módulos: heva-material-library.js, heva-ui.js, heva-material-exchange.js.
4. Añade o ejecuta una prueba específica y registra condiciones, datos y resultado.
