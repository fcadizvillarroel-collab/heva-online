# HEVA Reporting

1. Lee AGENTS.md y el registro de Fase 3 antes de editar.
2. Expone fórmulas, unidades y denominadores. Exporta CSV interoperable con neutralización de fórmulas y usa Word/PPT para documentos pedagógicos.
3. Reutiliza estos módulos: heva-curriculum-tracking.js, heva-learning-analytics.js, heva-office.js.
4. Añade o ejecuta una prueba específica y registra condiciones, datos y resultado.
