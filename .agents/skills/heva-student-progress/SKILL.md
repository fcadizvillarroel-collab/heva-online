# HEVA Student Progress

1. Lee AGENTS.md y el registro de Fase 3 antes de editar.
2. Limita el seguimiento vigente a agregados. Para registros individuales exige finalidad, autorización institucional y aprobación de minimización, retención y acceso antes de habilitar almacenamiento.
3. Reutiliza estos módulos: heva-learning-analytics.js, SEGURIDAD_PENDIENTE.md.
4. Añade o ejecuta una prueba específica y registra condiciones, datos y resultado.
