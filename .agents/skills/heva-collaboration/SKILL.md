# HEVA Collaboration

1. Lee AGENTS.md y el registro de Fase 3 antes de editar.
2. Reutiliza el intercambio de copias y el historial. Conserva la versión de origen, marca autoría autodeclarada y protege las pautas. Para acceso remoto exige permisos comprobados.
3. Reutiliza estos módulos: heva-material-exchange.js, heva-ui.js.
4. Añade o ejecuta una prueba específica y registra condiciones, datos y resultado.
